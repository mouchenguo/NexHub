NexHub 是面向 Windows 的共享与远程主机客户端：文件共享、OSS 长期缓存、临时穿透、RDP 主机、同账号在线设备和 NPS 隧道集中管理。

Windows 10 / 11 · 单文件安装包 · 当前版本 v0.1.0-beta
NexHub · 工作台
Features

一个客户端，覆盖常用协作场景

◈

文件共享

按文件或文件夹发布共享，支持临时穿透与 OSS 长期缓存，生成可访问的分享链接。

◍

RDP 主机

保存常用 Windows 远程桌面连接，使用系统原生 mstsc，密码本地加密保存。

⌁

同账号在线设备

同一账号的电脑自动上报在线状态，在其他设备上直接发现并连接。

↗

NPS 内网穿透

一键自动配置 NPC：服务器创建主机与隧道，客户端写入配置并重启服务。

✦

插件工具箱

内置内存优化等工具，支持生成自定义插件模板，保存后即时加载。

◎

注册与审核

客户端内直接注册，服务端默认自动审核；也可切换人工审核并在后台通过或拒绝。

◐

轻量本地数据

配置保存在本机，登录凭证加密存储；关闭窗口后可通过托盘继续运行。

System

运行要求

  • 操作系统Windows 10 / 11
  • 架构x64
  • 网络可访问 ECS / NPS
  • 可选组件NPS NPC（RDP / 临时共享）
Release Notes

v0.1.0-beta

  • 新增 NPC 一键自动配置：服务器自动创建/修复 NPS 主机与 TCP 隧道。
  • 客户端自动安装 NPC、写入 npc.conf、重启服务并显示公网 RDP 地址。
  • NPS 客户端或隧道丢失时自动重建，已有 vkey 可幂等复用。
  • 保留注册自动审核、管理后台审核和现有账号密码。
  • Release 客户端资产只保留一个 NexHub-v0.1.0-beta.exe。

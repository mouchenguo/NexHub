安全与部署建议

生产环境上线前逐项确认

  • 修改初始管理员密码：在「用户管理」中为 admin 重置强密码。
  • 使用 HTTPS 部署管理后台，并设置安全 Cookie：NEXHUB_COOKIE_SECURE=true。
  • 使用反向代理限制 /admin 的访问来源（IP 白名单 / VPN）。
  • OSS 密钥仅存放在 ECS 环境变量，切勿提交到 Git 或写入客户端配置。
  • 定期备份 {{ cfg.db_path }} 与 OSS 元数据。
  • nps 服务端与管理 API 不要使用弱口令，并按需配置访问控制。
